# 我的羽球教練（PWA）

拍下學生的揮拍與握拍，和老師的示範比對關節角度、揮拍軌跡、速度與節奏，給出分數與具體的調整建議。所有影像辨識都在使用者的手機或電腦上完成，影片不會上傳。

## 功能

**揮拍比對**
- 用鏡頭直接錄影（前後鏡頭、4／6／10 秒、3 秒倒數、即時骨架與「全身入鏡」提示），或上傳手機裡的影片
- 修剪片段後逐幀擷取 33 個身體節點（MediaPipe Pose）
- 自動找出揮拍片段：以持拍手腕最快的瞬間當作擊球點，往前後延伸到手靜止
- 以 DTW（動態時間校正）對齊老師和學生的動作時間，不受揮拍快慢影響
- 評分 = 姿勢角度 45% ＋ 揮拍軌跡 25% ＋ 速度與節奏 30%
  - 姿勢角度：持拍手肘、手臂抬起、手腕、非持拍手、雙膝、肩髖扭轉、肩膀轉向、上半身傾斜
  - 揮拍軌跡：持拍手腕相對肩膀的位置（以軀幹長度換算，不受身高影響）
  - 速度與節奏：最快揮拍速度、引拍與隨揮的時間比例、動作時序
- 在「引拍頂點／擊球瞬間／收拍」三個時刻產生具體建議
- 結果頁：骨架疊圖慢動作重播、雙影片同步對照、角度變化曲線、各項細節表
- 左手持拍會自動鏡像，可以和右手老師的示範比對

**練習紀錄後台**（v10 新增）
- 學生用學校 Google 帳號登入一次，之後每次完成揮拍或握拍比對，App 會把練習紀錄送到老師的 Google 試算表
- 試算表上的信箱經過 Google 驗證，別人無法冒名；影片不會上傳
- 自動累計練習時間：只計算學生在練習畫面（選示範、錄影、分析、看結果、3D 實驗室）且 2 分鐘內有操作的時間
- 沒有網路時紀錄先存在手機，連上網路後自動補送，不會重複計算
- 老師在 App 的「練習紀錄」分頁看到全班統計：比對次數、累計練習時間、近 7 天練習、平均與最高分、最近練習時間，可依班級篩選、找出 7 天內沒有練習的學生
- 實驗組／對照組（v11）：匯入學生名單（學號、姓名、組別、班級），學生登入後依學校信箱或學號自動對應；統計頁提供各組與合併的比較（人數、綁定與參與人數、每人比對次數與練習時間、平均分數、第一次與最近一次分數、進步分數，以 M ± SD 表示），可限定統計期間，並可下載組別統計與學生明細 CSV
- 設定方式見下方「練習紀錄後台設定」與「實驗組與對照組」

**多球拆解與練習方法**（v9 新增）
- 一段影片（最長 30 秒，錄影可選 20 秒）裡有多次揮拍時，自動找出每一球並逐球和示範比對；影片頭尾被切掉一半的揮拍不列入
- 結果頁與 3D 實驗室上方可以切換每一球，標出最好與最需要調整的一球，並統計每個問題出現在幾球
- 3D 實驗室新增「多球拆解」摘要、目前畫面的即時數據表（教師、學生、差異，差異大的以紅字標示）
- 「學生與教師影片的不同之處」每一項都附上練習方法（做法、次數、檢查重點），並整理成「這一週的練習計畫」
- 練習方法的內容在 `js/analysis.js` 的 `DRILLS`，老師可以依自己的教學改寫

**動作分析3D實驗室**（v8 新增）
- 揮拍比對結果頁上方按「進入動作分析3D實驗室」，也可以從練習紀錄重新打開
- 藍色是老師示範、橘色是學生當次的動作，以立體骨架（圓柱骨頭、球形關節、地面格線）顯示
- 預設上下（手機直向）或左右（橫向）並列，也可以切換「重疊比較」（以髖部中心對齊、以軀幹長度統一大小）
- 拖曳旋轉、雙指或滾輪縮放，兩邊同步轉動；提供正面、側面、俯視快速視角
- 依時間對齊結果同步播放（0.25／0.5／1 倍速），時間軸標出引拍頂點、擊球瞬間、收拍
- 播放到關鍵時刻自動定格 1.5 秒，在差異最大的 3 個關節畫角度弧線並列出藍、橘數字
- 「學生與教師影片的不同之處」依差異大小排序，標示明顯或輕微；點一下會跳到該瞬間並把相關部位標紅閃爍
- 「和示範一致的地方」列出做對的部位
- 可展開原始影片，跟著 3D 畫面同步
- 老師在「確認示範」頁可以先預覽藍色 3D 骨架
- 3D 畫面由 App 內建的輕量 3D 引擎繪製，不需額外下載，舊手機也能使用；3D 深度為推估值，數據僅供參考

**握拍比對（引導式）**
1. 角度一：手背朝向鏡頭，手放穩 1.2 秒自動拍下
2. 角度二：拇指側朝向鏡頭
- 每個角度拍下後，在照片上點「握把頭（握把尾端）」和「握把上端」，計算握把與手的夾角和握的位置高低
- 學生每一步都會看到老師同角度的示範照片
- 評分：手指彎曲、拇指位置、食指張開、握把方向
- 手腕轉動：老師錄一段 5 秒示範影片，學生只觀看，不列入比對

**示範影片庫與紀錄**
- 老師新增的示範會發布到網站的 GitHub 專案（`library/` 資料夾），所有學生打開網頁都會看到同一份示範
- 學生不需要任何帳號；示範下載過一次後會暫存在裝置上，沒網路時仍可使用
- 練習紀錄保存在各自的裝置上

## 部署

PWA 與相機都需要 **HTTPS**（`localhost` 除外）。整個資料夾是純靜態檔案，不需要後端。

- **GitHub Pages**：把資料夾內容推到 repo，在 Settings → Pages 開啟即可
- **Netlify / Vercel / Cloudflare Pages**：直接拖曳資料夾上傳
- **本機測試**：在資料夾內執行 `python3 -m http.server 8080`，用電腦瀏覽器開 `http://localhost:8080`

手機用 Chrome 或 Safari 開啟網址後，可以「加入主畫面」安裝成 App。

第一次使用需要網路下載 MediaPipe 程式與模型（姿勢模型約 9 MB、手部模型約 7.5 MB），service worker 會把它們快取起來，之後可以離線使用。

## 老師與學生身分

- 一打開預設是**學生身分**：示範影片庫只能查看和選用示範，自己的揮拍影片在「揮拍比對」錄影或上傳
- **老師身分**才能新增、刪除和發布示範：到示範影片庫按「我是老師，登入」，或從右上角「設定 → 老師登入」
- 預設老師密碼：`usc-badminton`，請盡快更改
- 更改密碼：以老師身分到「設定 → 變更老師密碼」，輸入新密碼後按「產生設定碼」，再到 GitHub 編輯 `js/config.js`，把 `TEACHER_HASH` 那一行整行換掉並 Commit
- 老師密碼只控制畫面；真正能修改共享示範影片庫的是老師裝置上的 GitHub 權杖，學生沒有權杖就無法更動示範

## 練習紀錄後台設定（Google 試算表，老師做一次即可）

需要準備：老師的學校 Google 帳號、學生的學校 Google 帳號（可以和老師屬於不同網域或不同機構，例如老師 g2.usc.edu.tw、學生 gm7.usc.edu.tw），以及已經能發布示範的 GitHub 權杖。下載的壓縮檔中，`練習紀錄後台.gs` 放在 App 資料夾**外面**，它不用上傳到 GitHub。

### A. 建立試算表與程式
1. 用學校帳號打開 Google 雲端硬碟 → 新增 → Google 試算表，命名例如「羽球教練練習紀錄」
2. 試算表上方選單「擴充功能」→「Apps Script」
3. 刪掉編輯器裡原本的內容，用記事本打開 `練習紀錄後台.gs`，全選複製貼上，按儲存
4. 在最上方 `CONFIG` 填入兩個值（`CLIENT_ID` 保持空白）：
   - `SCHOOL_DOMAIN`：學生信箱 @ 後面的部分，例如 `gm7.usc.edu.tw`；要讓老師帳號也能測試，用逗號加上第二個網域：`gm7.usc.edu.tw,g2.usc.edu.tw`
   - `TEACHER_KEY`：自己訂一串至少 12 個字的英文數字，老師查看全班統計時要用

### B. 啟用並部署兩次（不需要 Google Cloud）
同一份程式要部署**兩次**，兩個網址用途不同：

| 部署作業 | 存取權 | 用途 |
| --- | --- | --- |
| 第一個：紀錄網址 | 所有人 | 學生的 App 送練習紀錄、老師查詢統計 |
| 第二個：學生綁定頁 | 學校機構內所有人（例如「實踐大學」） | 學生用學校帳號打開，取得 6 位數綁定碼 |

1. Apps Script 上方函式選單選 `setup`，按「執行」。第一次會要求授權：選自己的帳號 → 進階 → 前往（不安全）→ 允許（這是你自己的程式）。執行紀錄出現「設定完成」即可；出現「設定還沒完成」就依訊息補上 CONFIG
2. 右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」→ 執行身分：**我**；存取權：**所有人** → 部署 → 複製網址（這是「網頁應用程式網址」）
3. 再按一次「部署」→「新增部署作業」→ 類型「網頁應用程式」→ 執行身分：**我**；存取權：**學校機構內所有人**（選項名稱是學校名稱，例如「實踐大學」）→ 部署 → 複製網址（這是「學生綁定頁網址」）
4. 測試：用瀏覽器打開兩個網址（不用加任何東西）。「紀錄網址」會顯示「✅ 練習紀錄後台運作正常」；「學生綁定頁網址」會直接顯示你的學校帳號和 6 位數綁定碼。綁定頁出現的是「運作正常」說明頁，代表沒認出學校帳號，請照頁面上的提示檢查

必須用**學校帳號**建立試算表與部署，學生也要用同一所學校的 Google Workspace 帳號，綁定頁才能取得學生信箱。學校如果只開放「機構內所有人」、沒有「所有人」可選，第一個部署作業會無法使用，請洽資訊中心開放。

### B2. 建立綁定表單（學生和老師是不同機構時必做，建議一律使用）
學生綁定頁只認得「和老師同一個機構」的帳號。學生帳號屬於別的機構（例如老師 g2、學生 gm7）時，改用程式自動建立的 Google 表單驗證學生的學校信箱：
1. Apps Script 上方函式選單選 `setupForm`，按「執行」。第一次會再要求授權（多了「Google 表單」「觸發條件」權限）：選自己的帳號 → 進階 → 前往（不安全）→ 允許
2. 執行紀錄會出現「綁定表單已建立。編輯網址：…」。打開這個網址 →「設定」→「回覆」，確認：
   - 「收集電子郵件地址」是「**經過驗證**」
   - 「只限 實踐大學（或你的機構）的使用者」**關閉**（否則其他機構的學生打不開）
   - 「限制每人只能回覆 1 次」**關閉**
3. 到「部署」→「管理部署作業」，兩個部署作業都按鉛筆圖示 → 版本「新版本」→「部署」（網址不變）
4. App 不用改任何設定：學生的「綁定學校帳號」頁會自動出現「開啟綁定表單」
5. 表單的回覆在完成綁定後會自動刪除，不會留下資料；不要刪除這份表單，也不要修改它的題目

學生流程：App →「開啟綁定表單」→ 確認右上角是學校帳號 → 按「提交」→ 回到 App，幾秒內自動完成綁定。表單打開時要求登入的不是學校帳號，就按「複製表單網址」貼到無痕視窗，只登入學校帳號送出，再回 App 按「我已送出」。

學校的 Google 管理員可能禁止表單接受機構外的帳號回覆；學生打開表單出現「您需要權限」時，請洽資訊中心開放「允許機構外的使用者回覆表單」。

### C. 在 App 裡填入
1. 用老師身分打開 App →「設定」→「練習紀錄後台設定」
2. 填入：網頁應用程式網址、學生綁定頁網址（使用綁定表單時可以空白）、學校信箱網域（學生的網域寫在第一個，例如 `gm7.usc.edu.tw,g2.usc.edu.tw`）、查詢金鑰（OAuth 用戶端 ID 不用填）
3. 按「檢查連線」，出現「連線成功，後台設定完整」後，按「儲存並發布」。學生重新打開 App 約 1 分鐘後，就會出現「綁定學校帳號」

### D. 學生怎麼綁定
有建立綁定表單時，學生用上面 B2 的表單流程即可。沒有建立表單（老師和學生同一個機構）時：
1. App 的「綁定學校帳號」頁 → 按「開啟學校帳號綁定頁」→ 用學校 Google 帳號登入 → 頁面顯示 6 位數綁定碼
2. 回到 App 輸入綁定碼 → 按「綁定」。10 分鐘內有效，只能用一次
3. 瀏覽器同時登入多個 Google 帳號時，綁定頁可能打不開或顯示其他帳號：按 App 裡的「複製綁定頁網址」，開無痕視窗（iPhone Safari 的「私密瀏覽」、Chrome 的「無痕分頁」）貼上網址，只登入學校帳號。在哪個瀏覽器取得的綁定碼都可以用
4. 每台裝置只要綁定一次。iPhone 請先「加入主畫面」，再從主畫面的 App 綁定（主畫面 App 和 Safari 的資料是分開的）
5. 學生姓名以「學生名單」為準；沒有匯入名單前，統計頁會先顯示學校帳號名稱

### E. 實驗組與對照組
1. 用 Excel 或 Google 試算表準備名單，五欄依序是：學號、姓名、組別、班級、學校信箱（信箱可以空白）。組別寫「實驗組」或「對照組」。壓縮檔裡的 `學生名單範本.csv` 可以直接套用
2. 老師身分打開 App →「練習紀錄」分頁 →「匯入學生名單」→ 選取整個表格複製貼上（或選擇 CSV 檔）→ 確認預覽 →「匯入名單」。新名單會取代舊名單，練習紀錄不受影響
3. 也可以直接在 Google 試算表的「學生名單」工作表貼上名單，再從試算表上方選單「羽球教練 → 更新組別統計」
4. 對應方式：先比對名單上的學校信箱，再比對學號（不分大小寫；數字部分相同也算，例如信箱帳號 s1130101 對應學號 1130101）。對應不到的帳號列為「未分組」，補進名單後重新匯入即可
5. 統計頁上方可以設定「統計期間」（例如實驗介入期間）；「組別比較」表列出實驗組、對照組與全部合併；可下載「組別統計」與「學生明細」CSV，直接用 Excel、SPSS 或 R 分析
6. 試算表的「組別統計」工作表會在每次有新紀錄或匯入名單時自動更新（全部期間）；「練習紀錄」每一列也會標上組別

統計說明：
- 「M ± SD」是每位學生數值的平均與樣本標準差
- 名單上但沒有綁定帳號的學生，比對次數與練習時間以 0 計入（方便看出參與情形）
- 分數類只計算有分數的學生；「進步分數」＝最近一次分數 − 第一次分數，只計算期間內比對兩次以上的學生
- 分數為 App 與教師示範比對的相似度分數，不同示範之間的難度不同；若要比較進步，建議兩組在期間內使用相同的示範

### 之後要知道的事
- 試算表會自動建立六個工作表：「練習紀錄」（每次比對一列）、「練習日誌」（對照組每筆日誌一列）、「學生總覽」（每位學生一列，自動累計）、「學生名單」、「組別統計」、「綁定裝置」（已隱藏，請不要修改）
- 已經部署過舊版程式時：把新版 `練習紀錄後台.gs` 整份貼上取代（記得保留自己的 CONFIG 三個值），再「部署 → 管理部署作業 → 編輯 → 新版本」
- 修改 Apps Script 程式後，要「部署」→「管理部署作業」，**兩個部署作業都要**按鉛筆圖示 → 版本選「新版本」→「部署」，網址不會改變
- 查詢金鑰只存在老師自己的裝置；換手機時要重新輸入
- 學生換手機或使用已安裝的 App 時：在原本裝置的「設定 → 我的帳號與練習時間」產生 6 位數綁定碼，到新裝置輸入即可


### 選用：Google 登入按鈕（需要 Google Cloud）
學校允許使用 Google Cloud 時，可以另外加上「使用 Google 帳號登入」按鈕，學生不用切換到綁定頁：
1. console.cloud.google.com 建立專案 →「OAuth 同意畫面」（Google 驗證平台）→ 目標對象選「內部」
2. 建立「網頁應用程式」用戶端，「已授權的 JavaScript 來源」填 `https://你的GitHub帳號.github.io`
3. 把用戶端 ID 填到程式碼的 `CLIENT_ID` 和 App 設定的「OAuth 用戶端 ID」，再「管理部署作業 → 編輯 → 新版本」
出現「很抱歉，您無法使用 Google Cloud Platform」代表學校帳號沒有開放，使用上面的學生綁定頁即可。

## 對照組 App：我的羽球練習日誌

`journal/` 資料夾是給對照組使用的「我的羽球練習日誌」，網址是 App 網址後面加 `/journal/`，例如 `https://dreric945.github.io/badminton-coach/journal/`。

- 學生可以看老師發布的示範影片（和「我的羽球教練」是同一份示範影片庫，可慢速播放），課餘自主練習
- 每次練習後寫一筆日誌：練習日期、練習的動作、練習時間（分鐘）、揮拍次數（必填），練習說明（選填）
- **練習照片只存在學生自己的手機**：學生可以拍照或從相簿選一張照片加在自己的日誌裡，但照片**不會上傳**給老師、試算表或任何雲端。送給老師的只有文字資料和「有沒有附照片（是／否）」。學生換手機或清除 App 資料後照片會不見，想保留請自行另存
- 介面和操作方式與「我的羽球教練」相同，改用淡粉色系（校徽顏色不變）；沒有動作分析功能
- 學校帳號綁定方式相同（綁定表單）。日誌先存在手機，綁定後自動送出；沒有網路時連上後自動補送
- 資料進入同一份 Google 試算表的「練習日誌」工作表（每筆一列：時間、信箱、姓名、班級、學號、練習日期、練習動作、練習時間、揮拍次數、練習說明、有附照片、App 版本、紀錄編號、組別）
- 「學生總覽」多了「日誌次數、日誌練習時間（分）、日誌揮拍次數」三欄；「組別統計」與 App 的「全班練習統計」加入日誌的筆數、自填時間與揮拍次數，以及「比對＋日誌」的合計
- 日誌的期間篩選以學生填的「練習日期」計算

第一次使用前，老師要做：
1. Apps Script 貼上新版程式（保留 CONFIG），執行一次 `setup`（建立「練習日誌」工作表；不需要雲端硬碟權限）
2.「部署 → 管理部署作業」，兩個部署作業都更新成「新版本」
3. 把整個 App 資料夾（含 `journal/`）上傳到 GitHub
4. 在學生名單中把對照組學生的組別填「對照組」

## 共享示範影片庫設定（老師做一次即可）

學生和老師看到同一份示範，是因為示範存放在這個 GitHub 專案裡。老師的裝置需要一組 GitHub 權杖（token）才能寫入：

1. GitHub 右上角頭像 → **Settings** → 左側最下方 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. Token name 填「羽球教練示範」；Expiration 選一個期限（到期後要重新產生）
4. Repository access 選 **Only select repositories**，選這個網站的專案
5. Permissions → Repository permissions → **Contents** 改成 **Read and write**
6. 按 **Generate token**，複製 `github_pat_` 開頭的權杖（只會顯示一次）
7. 在 App 用老師身分登入 → 示範影片庫 → **設定 GitHub 權杖**，貼上後按「檢查並儲存」

權杖只存在老師那台裝置，不要傳給學生。發布後 GitHub Pages 約 1 分鐘會更新，學生重新整理就會看到。

## 建議的使用流程

1. 老師登入老師身分並設定 GitHub 權杖
2. 到「示範影片庫」→「新增揮拍示範」，錄一次標準動作、確認骨架後按「儲存示範」，系統會自動發布
3. 新增握拍示範：拍兩個角度並標出握把頭，再錄一段手腕轉動示範影片（只供學生觀看）
4. 學生打開網頁，到「揮拍比對」或「握拍比對」選示範開始練習

## 拍攝建議

- 手機固定（腳架或靠在牆邊），和示範用**相同的角度與距離**；2D 影像對拍攝角度很敏感
- 揮拍：全身入鏡、距離 3 到 4 公尺、光線充足、每段只做一次揮拍
- 揮拍很快時，在設定中改為「每秒 60 張」，並用 60fps 錄影
- 握拍：手距離鏡頭 40 到 60 公分，背景越單純越好
- 老師與學生建議使用同一種「姿勢辨識精度」設定

## 限制

- 系統只偵測人體與手部關節，**看不到球拍本身**。揮拍軌跡以手腕代替拍頭；握拍時要靠手動標記球拍方向
- 手握住拍柄時手指會被遮住，模型會推測被遮住的關節，精度有限
- 網球東方式／西方式這類「拍柄稜面」的差異，單靠手部關節難以分辨，建議搭配球拍標記或老師確認
- 3D 實驗室的前後深度是從單一鏡頭推估，身體前後方向的角度可能有 10° 到 20° 誤差
- 世界座標的深度（z）誤差較大，側面與正面拍攝得到的角度不同，請固定拍攝角度
- 示範影片放在公開的 GitHub 專案裡，知道網址的人都看得到；單一影片上限 100 MB，整個網站建議不超過 1 GB

## 後續可以擴充

- 後端示範影片庫與帳號（老師上傳後學生直接看到、跨裝置同步、老師查看學生紀錄）
- 球拍偵測模型（例如自訓 YOLO），取得拍頭軌跡與拍面角度
- 老師在示範影片上手動標記「引拍頂點／擊球／收拍」，取代自動偵測
- 需要 120/240fps 高速錄影時，再用 Flutter／React Native 做原生版本
